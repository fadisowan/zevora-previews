# Zevora previews

Static images for the Zevora Salla theme, served through jsDelivr with commit-pinned URLs:

- `sections/` — editor thumbnails for each home section (`image` in twilight.json)
- `defaults/` — default photos a section shows until the merchant uploads their own
- `screens/` — store screenshots

Nothing here is code. The theme itself lives in a separate private repository.
